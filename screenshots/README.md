# Скриншоты

Сняты Chromium с реальных страниц текущей production-сборки, без дорисовки интерфейса.

- `redesign-main.png` — главная, 1440 px.
- `redesign-catalog.png` — каталог и категории.
- `redesign-mobile.png` — главная, 390 px.
- `redesign-admin.png` — настройки изображений, баннера, цветов и шрифта.
- `redesign-analytics.png` — аналитика без выдуманной выручки.
- `recent-purchases.png` — блок свежих покупок при отсутствии подтверждённых оплат.
- `test-mode-admin.png` и `test-purchase-mobile.png` — проверка тестовой покупки за 0 ₽ на отдельной тестовой базе; отображён один действительно созданный тестовый заказ.

Аватарка GT из сообщения пользователя не была доступна как файл в рабочей среде. На снимках текстовая заглушка GT; собственное изображение загружается в «Оформлении».
