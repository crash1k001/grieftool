# Проверка безопасности и работоспособности

Дата: 2026-11-03 (Asia/Tashkent). Проверен код этой версии, локальная production-сборка Next.js, изолированная SQLite и Chromium. Это проверка известных сценариев, не гарантия отсутствия всех уязвимостей.

## Что изменено

- Проверки прав на сервере: только владелец меняет команды выдачи, оформление, политики, сотрудников и тестовый режим. Администратор не может повысить свою роль.
- Публичный каталог не раскрывает команды, сессии, полные ники покупателей или номера чужих заказов. Новая лента читает только шесть последних оплат через индекс SQLite.
- Тестовый режим управляется сервером: статус `test`, сумма 0, отдельная метка `isTest`. Подмена суммы/статуса/режима в запросе не включает бесплатную покупку. Смена режима во время оформления возвращает 409.
- Тестовые заказы исключены из финансовой аналитики, публичной ленты и учёта использований промокодов. Очистка удаляет только записи с обеими тестовыми метками; действие журналируется.
- Лимит API: 300 запросов в минуту на доверенный IP либо 1200 на общий процесс без доверенного прокси. Чужим заголовкам IP доверие выключено по умолчанию; Caddy перезаписывает доверенный заголовок.
- Размер JSON до 256 КБ; чтение тела ограничено по размеру и времени, включая поток без Content-Length. Загрузка изображения ограничена 5 МБ, размерами, числом кадров и типом содержимого. SVG отклоняется, пути файлов определяются SHA-256.
- Настроены Content-Security-Policy, X-Frame-Options, nosniff, Referrer-Policy, Permissions-Policy. В production нет unsafe-eval. Системные ошибки не возвращают пути файлов.
- Поддержка удалена из интерфейса; API обращений закрыт с кодом 410. Старые переписки не публикуются и не удаляются автоматически.
- Production Docker-образ включает public: локальные картинки и favicon доступны после развёртывания.
- CSV доступен только авторизованной команде: фильтры валидируются, формулы и кавычки экранируются, скачивание журналируется. Тексты главной выводятся через экранирование React, без HTML-вставки.
- Массовая видимость товаров меняет только флаг публикации в транзакции; не меняет команды выдачи. При отсутствующем товаре вся операция отменяется.

## Проверки

`npm test` — цены, промокоды, scrypt, сессии и отзыв доступа, роли, миграция, серверные акции, скрытие команд, лимиты тела/времени/запросов, приватность покупателей, сезонные награды и идемпотентность.

`npm run build` и `node scripts/test-all.mjs` — production-сборка, пять API-наборов и пять браузерных наборов. Каждый набор получает отдельный сервер, новую базу и случайные секреты. Проверяются магазин, CRUD товаров/новостей/правил/сотрудников, Origin, права, собственные изображения, favicon, скидки, аналитика, оформление, тестовая покупка за 0 ₽, выборочная очистка, мобильные размеры 360/390 px и сезонные эффекты.

`npm audit --omit=dev` — проверка известных уязвимостей зависимостей на дату выполнения. Caddyfile валидируется официальным образом Caddy. Скриншоты реальных страниц сохранены в `screenshots/`; браузерные фикстуры — в `test-results/` и не включаются в Git.

## Ограничения и эксплуатация

- Против объёмного DDoS нужны защита хостинга/CDN/WAF и ограничение прямого доступа к origin. Публичный хостинг, сетевой канал и внешняя инфраструктура в этой среде не проверялись. Нагрузочная атака не проводилась.
- Лимиты приложения рассчитаны на один процесс. Для нескольких реплик нужен общий лимитер и общая согласованная база. При рестарте общий лимит запросов в памяти сбрасывается; ограничения входа хранятся в SQLite.
- CSP содержит unsafe-inline для гидратации Next.js. Она ограничивает внешние источники и встраивание, но не заменяет экранирование текста и не является строгой nonce-политикой.
- Нужны HTTPS, длинный пароль владельца, резервные копии SQLite **и медиатеки**, контроль диска, обновления зависимостей и мониторинг. Не публикуйте `.env`, базу, сессии и BRIDGE_TOKEN.
- Платёжный провайдер и выдача платных товаров не подключены. Команды товаров хранятся как настройки, тестовые покупки ничего не выполняют в Minecraft. Нет оснований утверждать, что оплата или доставка проверены на живом игровом сервере.
- Оператор данных, контакты и условия возврата заполняются владельцем до продаж. Заготовленные документы нельзя считать автоматически подходящими для любой юрисдикции.
